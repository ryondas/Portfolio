GT Movies Store

GT Movies Store is a Django web application that lets users browse a catalog of movies, read and leave reviews, manage a shopping cart, and track their past orders. Administrators can manage the full catalog, users, and reviews through a dedicated admin interface. It was built end to end — models, views, templates, authentication, and deployment — following the assignment's required user stories.

  • BrowsingView and search the movie catalog, see full details and pricing for each title.
  • AccountsSign up, log in, and log out with a custom Django authentication flow.
  • ReviewsLogged-in users can write, edit, delete, and report reviews on any movie.
  • Cart & ordersAdd movies to a cart, adjust quantities, complete a purchase, and view order history.
  • Admin toolsFull management of users, movies, reviews, and orders through Django's admin site.
  • Responsive designBuilt with Bootstrap so the layout adapts across desktop, tablet, and mobile.

How I built it

I worked through this project step by step, following Django 5 for the Impatient as my primary guide and extending past it wherever the assignment's requirements went further than the book did.

  • Chapter by chapter I moved through the book in order, since each chapter's code builds directly on the last — templates before models, models before authentication, authentication before reviews and the cart.
  • Build, run, break, fix Most of my actual learning happened in the debugging loop: write code, run the server, read the traceback, and figure out exactly which line caused it. A recurring source of bugs was invisible character corruption from copying multi-line code out of the book's PDF — I got fast at spotting and retyping those by hand.
  • Version control and deployment I tracked my work in Git and pushed to GitHub, then deployed the finished app to PythonAnywhere — configuring the WSGI file, the virtual environment, static files, and allowed hosts to get it running in production.
  • Navigating doubt When I got stuck, I leaned on the assignment's authorized resources — the textbook, official Django docs, and Stack Overflow — and worked through error messages methodically rather than guessing at fixes.
